# Customer Segmentation Dashboard

A beginner-friendly machine learning project that groups telecom customers  into segments based on how they use their phone, and shows the results in an interactive dashboard.

> **Note:** Real operator data is confidential, so this project uses **5,000 synthetic (fake) customers** generated by a Python script.

## The problem

Marketing teams often send the same offer to every customer. Many campaigns are wasted because nobody knows what types of customers exist or how big each group is.

## The solution

1. Generate realistic customer data
2. Clean the data
3. Use **K-Means clustering** to find 5 customer segments automatically
4. Explore the segments in a **Streamlit dashboard** with a suggested marketing action for each one

## The 5 segments found

| Segment | What defines it | Suggested action |
|---|---|---|
| **Low spenders** | Low use of everything, small top-ups | Small, cheap top-up promotions |
| **Students** | Lots of data and SMS, newest customers | Social media packs, cheap night data |
| **Data lovers** | About 30 GB of data, few calls | Bigger data bundles, night packs |
| **Talkers** | Many call minutes, very little data | Unlimited-call plans, bonus minutes |
| **Premium** | High on everything, highest spend, longest tenure | Loyalty rewards, roaming packs |

## Results

The synthetic data contains a hidden column with each customer's true type. The model never sees it, so it can be used to check the result afterwards. K-Means placed about **93.5%** of customers in the matching segment. The main confusion was between *Data lovers* and *Students*, which both use a lot of data.

Because the data is synthetic, this score is optimistic. Real customer groups overlap much more.

## Dashboard features

- Number of customers and size of each segment
- Average profile of each segment
- Drop-down menu with a suggested marketing action per segment
- Customer lookup: enter an ID (for example `C00004`) to see the customer's segment and how they compare with the segment average
- Segment mix per wilaya

## How to run it

**1. Install the libraries**

```
pip install pandas numpy scikit-learn streamlit matplotlib jupyter
```

**2. (Optional) Recreate the data**

```
python generate_data.py
```

**3. Start the dashboard**

```
python -m streamlit run app.py
```

If the `streamlit` command is not found on Windows, the `python -m` form above avoids the problem.

**4. (Optional) Open the notebook**

```
python -m notebook
```

## Method, step by step

1. **Data generation:** 5 hidden customer types, each with its own average and spread, plus random noise, about 3% missing values, and a few extreme outliers on purpose.
2. **Cleaning:** missing values filled with the median; extreme `data_gb` values capped at the 99th percentile (59.7 GB).
3. **Scaling:** `StandardScaler`, so that columns with big numbers (spend in DA) do not dominate columns with small numbers (GB).
4. **Clustering:** K-Means with K = 5 on six features: `data_gb`, `voice_min`, `sms_count`, `monthly_spend_da`, `topup_count`, `tenure_months`.
5. **Naming:** each segment named by reading its average behavior.
6. **Visualization:** PCA reduces the 6 features to 2 so the segments can be drawn as a scatter plot.
7. **Dashboard:** built with Streamlit.

## Limitations and next steps

- The data is synthetic.
- K = 5 was chosen by hand. Next step: test K from 2 to 8 with the elbow method and the silhouette score.
- Next step: add an LLM that writes a short campaign message for each segment.
- Next step: add a map of segments per wilaya.
